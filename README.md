## 🌟 نظرة عامة
**جراند ستاي PMS** هو نظام متطور لإدارة المنشآت الفندقية والضيافة، مصمم بأحدث معايير تجربة المستخدم وتصميم الزجاج المصنفر (Frosted Glassmorphism) مع دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (RTL) بالإضافة إلى خطوط احترافية متناسقة.

---

## ✨ الميزات الرئيسية

- 🏢 **لوحة تحكم ذكية (Smart Dashboard):** إحصائيات فورية حول الإشغال، الإيرادات اليومية، وحجوزات اليوم.
- 🛏️ **إدارة الغرف والأجنحة:** استعراض حالة الغرف (شاغرة، مشغولة، قيد التنظيف، صيانة).
- 📅 **نظام الحجوزات المتقدم:** تسجيل وتعديل الحجوزات السريعة ومتابعة النزلاء.
- 👤 **إدارة ملفات النزلاء (VIP & Guests):** متابعة تفضيلات النزلاء وتاريخ إقامتهم.
- 🎨 **تصميم زجاجي عصري (Dreamy Pastel Glassmorphism):** تدرجات لونية ناعمة، تأثيرات إضاءة ديناميكية، وتجربة تصفح متجاوبة لجميع الشاشات.
- ⚡ **أداء فائق:** ملفات مُصغّرة ومحسنة للإنتاج السريع (`style.min.css`, `app.min.js`).

## 🚀 طريقة التشغيل

المشروع جاهز للعمل مباشرة دون الحاجة لأي خوادم معقدة:
1. قم باستنساخ المستودع:
   ```bash
   git clone https://github.com/Zahraaqaiss555/GrandStay-PMS.git
   ```
2. ادخل إلى المجلد وافتح ملف `index.html` في أي متصفح ويب حديث:
   ```bash
   cd GrandStay-PMS
   start index.html
   ```
